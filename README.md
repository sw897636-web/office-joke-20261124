A [make.fun](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) entry for
"One-Line Office Joke: 24-Hour Sprint": one line, at most 200 characters — a
joke about office life.

## The entry

> The office fridge has a yoghurt from 2019 with its own parking space, and nobody dares move it because by now it outranks us all.

129 characters, one line, no trailing newline.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the joke
deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```

`candidates.md` holds six original candidate lines, each scored against the
house judge's five criteria, with the reasoning for the final pick.
